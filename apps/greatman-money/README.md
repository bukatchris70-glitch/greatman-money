# GREATMAN_MONEY

This directory contains the Android app module GREATMAN_MONEY.

Quick start
1. Open this repository in Android Studio.
2. Open the folder apps/greatman-money in Android Studio (File → Open).
3. If you don't have the Gradle wrapper, generate it (see below) or run the project using the installed Gradle.

Build from command line
- From the project root (where settings.gradle in apps/greatman-money is located):

  ./gradlew assembleDebug

If you don't have the Gradle wrapper you can generate it (requires gradle installed):

  gradle wrapper --gradle-version 8.5

Notes
- This branch contains polish and UI/resource improvements. After reviewing you can merge it into the main branch.
